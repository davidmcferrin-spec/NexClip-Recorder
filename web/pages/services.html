Signal

SDI lock comes from nexrec-decklink-status (NEXREC_DECKLINK_STATUS_BIN or Setup). The helper prints JSON per sub-device (input_locked, input_mode, busy). A busy connector — the recorder already has it open — still reports lock and format. Without the helper the row stays unknown and keeps the last format the record worker stored. DeckLink preview units are skipped; the proxy is teed inside nexrec-record. IP rows use the worker heartbeat and last chunk time.
